---
Avslutt dagen. Følg CLAUDE.md. Eleven er sliten, hold det kort.

1. Still de tre loggspørsmålene, **ett om gangen**, og vent på svar mellom hvert: Hva lærte du i dag? Hva var vanskelig? Hva lurer du på?
2. Er et svar tomt eller bare «vet ikke»: ett oppfølgingsspørsmål, ikke flere. Så neste spørsmål.
3. Lag dagens loggoppføring som en markdown-blokk i samme format som `rapport/LOGG.md` (`## Dag N – <dato>`, Lærte / Vanskelig / Lurer på), for første tomme dag. Bruk elevens egne ord, bare rettet for skrivefeil. Ikke legg til noe eleven ikke har sagt, og ikke be om omskriving. Eleven limer blokken inn i stedet for den tomme seksjonen.
4. Be om `git status` og lim-inn. Er noe ikke committet eller pushet: gi kommandoene, én om gangen. Er milepælen ferdig: minn om PR og kryss i milepælfila i én setning. Gjelder ikke dag 1.
5. Si i én setning hva som står for tur i morgen. Ikke forklar det.
6. Dagen er ferdig når loggen er limt inn og git er rent. Si ha det, og ikke still flere spørsmål. Én tørr spøk er tillatt.
