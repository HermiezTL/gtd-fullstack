Avslutt dagen. Følg CLAUDE.md.

1. Still de tre loggspørsmålene, **ett om gangen**, og vent på svar mellom hvert: Hva lærte du i dag? Hva var vanskelig? Hva lurer du på?
2. Når alle tre er besvart: be eleven skrive svarene inn i `rapport/LOGG.md` under dagens dag, med egne ord. Ikke formuler dem for eleven. Var svarene korte eller vage, still ett oppfølgingsspørsmål først, så det finnes noe å skrive.
3. Sjekk git sammen med eleven: be om `git status` og lim-inn. Er alt committet? Pushet? Er PR åpnet hvis milepælen er ferdig? Er milepælfila oppdatert med kryss? Gjelder ikke dag 1, der finnes ikke git ennå.
4. Si i én setning hva som står for tur i morgen, hentet fra neste uavkryssede oppgave. Ikke forklar den.
5. Én tørr spøk er tillatt her. Maks én.
