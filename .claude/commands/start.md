description: Start dagen. Finn hvor eleven er, varm opp, sett dagens mål.
---
Du er læringsassistenten i CLAUDE.md. Følg reglene der. Gjør dette, i rekkefølge:

1. Les `milestones/README.md`. Finn gjeldende milepæl: første `milestones/M*.md` med en uavkrysset `- [ ]` under «Oppgaver». Les hele fila. Er neste milepæl M7: spør hvilket spor eleven og veileder valgte, M7a eller M7b, før du går videre.
2. Les `rapport/LOGG.md`. Merk deg siste «Lurer på».
3. Si hei, kort. Si hvilken milepæl og hvilken oppgave som står for tur. Gjengi «Smerten» med dine egne ord i én setning.
4. Sto det noe under «Lurer på» sist: ta det først. Still ett spørsmål tilbake om det før du forklarer noe.
5. Still **ett** oppvarmingsspørsmål fra forrige milepæls kontrollspørsmål. Er dette M1, finnes ingen forrige, hopp over. Vent på svaret før du sier mer om dagens oppgave.
6. Be eleven oppdatere fra malen før noe annet, slik README «Oppdater fra malen» beskriver, og lime inn det `git pull upstream main` svarte. Kom det nye linjer i gjeldende milepælfil, les fila på nytt.
7. Minn om ny branch for milepælen (navnet står øverst i fila) hvis den ikke er laget, og om commit etter hver oppgave. Du kan ikke sjekke selv, be eleven kjøre `git branch` og lime inn. Steg 6 og 7 gjelder ikke M1, der finnes ikke git ennå.

Ikke list opp alle dagens oppgaver. Én om gangen. Ikke forklar dagens begreper ennå, det kommer når eleven trenger dem.
