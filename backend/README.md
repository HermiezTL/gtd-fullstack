# backend

Tom med vilje. Serveren din starter her i M3, oppgave 3.1.

Når du er ferdig med M6 ser mappa omtrent slik ut:

```
backend/
  server.js        Express-appen og rutene
  db.js            koblingen til Postgres
  openapi.yaml     API-beskrivelsen Swagger leser
  package.json     avhengigheter og npm-scripts
  .env             hemmeligheter, ikke i git
  .env.example     mal for .env, i git
  Dockerfile       oppskriften for å pakke serveren
  .dockerignore
```

Slett denne README-en når `server.js` finnes.
