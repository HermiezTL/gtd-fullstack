# frontend

Her bor nettleserkoden din. Tre filer:

- `index.html` – strukturen
- `style.css` – utseendet
- `app.js` – oppførselen

Dag 1-koden din flyttes hit i M2, oppgave 2.3. Fra M4 serveres denne mappa av Express, så du åpner `http://localhost:3000`, ikke fila direkte.

Slett denne README-en når koden er på plass. Den har gjort jobben sin.
